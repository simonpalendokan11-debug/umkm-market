# UMKM Market — Front-End E-Commerce

Proyek pembelajaran E-Business System Pertemuan 7 menggunakan HTML, CSS, dan JavaScript.

## Fitur
- Katalog 8 produk lokal dengan pencarian dan filter kategori.
- Keranjang belanja, subtotal, dan validasi stok.
- Checkout dan simulasi status pesanan.
- Panel admin demo untuk pengelolaan pesanan dan penambahan produk.
- Data demo tersimpan pada localStorage browser.

## Menjalankan
1. Ekstrak ZIP dan buka folder di VS Code.
2. Buka `index.html`.
3. Klik kanan dan pilih **Open with Live Server**.
4. Koneksi internet dibutuhkan untuk foto produk dan Google Fonts.
